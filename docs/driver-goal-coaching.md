# Chauffeur goal status

The gauge has two colors: red below target and green at/above target, with the target centered. Neither the target margin nor extreme relative percentages are displayed. Backend position uses margin minus target in percentage points; the previous relative-to-profit formula is not used by this UI.

Only periods through the last common complete import cutoff with reconciled revenue, all costs, work time, personnel, fuel and overhead are eligible. `private.hub_driver_complete_windows_v1` records canonical unit, active report generation, covered date window and evidence references for each required component. Trusted backend reconciliation writes evidence only after source coverage and unit mapping are verified, including confirmed zero/not applicable components. An imported row, maximum transaction date, or a batch marked completed is not proof of completeness. No historical periods are automatically certified by these migrations. Existing imports lack sufficient explicit completeness evidence; until reconciled the view intentionally shows a waiting state rather than guessed performance.

New report generations invalidate old certifications. The public period RPC validates active tenant membership, resolves the driver's canonical person, permits preview only to owners, and returns only periods for the driver's vehicle scope. Requests containing arbitrary dates cannot bypass backend completeness gates. Previous equal-length period and prior year comparisons are independently gated; missing comparison periods are omitted. Days and reporting remain available while economic completeness is pending.

No monetary amounts or private salary configuration are returned. Fuel suggestions remain bounded hypothetical savings at unchanged workload, with preliminary price caveats; trip counts are not invented.

Manual Monday uploads and future daily ingestion use the same coverage contract. Coverage is the intersection of verified source ranges, including confirmed zero/not applicable components, rather than a hardcoded weekday or monthly schedule. A day after the common cutoff never contributes to either side of a comparison. The default is the latest available window, limited to 28 days; no calendar-month restriction applies.
