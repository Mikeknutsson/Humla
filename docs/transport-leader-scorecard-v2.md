# Transportledar-KPI

`/kpi/transportledare` reads `hub_transport_leader_scorecard_v2`. The existing `/transport-styrning` address redirects there. The dashboard menu links to the page. The owner can configure dated responsibility at `/transport-styrning/admin` and set a dated margin target after opening an economic unit.

The report consumes published prepared display facts, including canonical shared-cost allocation and project exclusions. It never recomputes ingestion, distributes additional costs, or changes financial totals. An owner without a selected user sees KST 30, including rows without a unit. A selected user's report includes only assigned canonical units on each transaction's date, including work in other cost centres. `EXISTS` prevents duplicate assignments from multiplying transactions. Unit details apply the same authorization and date predicates before pagination and returning original evidence. Original evidence is never included in the unfiltered overview response.

Margin targets are private canonical EconomicUnit references. Owner-only RPC writes are serialized per tenant/unit, reject overlapping/future backfills, and end the preceding target one day before the new target. Target result is computed on each revenue row's effective target. Target margin is revenue weighted; any nonzero revenue without a target prevents reporting an incomplete aggregate target. No example goals or responsibility assignments are installed. Private-table deny-by-default RLS and intentional authenticated RPC definer access follow the existing Hub pattern; RPC authorization is tested explicitly.

Transport, material, tipping and other/shared categories reconcile to the unit totals. Costs without a verified article category remain shared; category results and margins stay unavailable while shared costs remain. Combined articles follow existing Hub separation only. This is an economic-unit perspective, not an implementation of order-area responsibility or an invented allocation of shared costs to orders.

Date range defaults to fiscal YTD through Stockholm's current day. Saved fiscal/month selections are preserved, including nonconsecutive months; selecting a new date range can explicitly clear the month filter. Prior-year cards shift both exact dates by one calendar year with leap-day clamping and retain the same months. Personal comparisons use that person's actual historical responsibility rather than reassigning last year's activity to today's owner.

Validation: TypeScript, ESLint, production build and rolled-back SQL regressions against published facts. SQL checks reconciliation, target changes within a month, weighted target result, overlap rejection, mid-month responsibility, non-owner isolation, cross-user denial and anonymous denial. Security advisor review confirms private storage has no direct grants; public RPC entry points intentionally check caller membership and owner/assignment scope. New tables and functions are additive; the existing v1 contract remains unchanged.

## Balance gauges and category comparisons (2026-10-22)

The page now consumes additive `hub_transport_leader_scorecard_v3`. It retains the same scoped facts, dated canonical targets and month selection; v2 remains available. Summary, units and business groups are aggregated in Hub with grouping sets. Group drilldown filters the published business group without adding assignments or redistributing costs. Unknown groups and categories remain visible and reconcile to the total.

Server-rendered SVG gauges show actual margin on a shared −100% to 100% scale, with a black target marker. Negative results are red, positive results below target amber, and nonnegative results meeting target green. Without complete dated targets, the positive arc remains grey. Nonpositive revenue has no margin; out-of-scale values retain their exact numeric label. Category tables separate revenue and costs, comparing amounts and revenue shares against the same prior-year date/month/assignment scope. Missing comparison periods remain unavailable.

Verification: production build, TypeScript and scoped ESLint passed. `supabase/tests/transport_balance_gauges_v3.sql` rolls back all test fixtures and verifies v2 total parity, group/category reconciliation, group drilldown, empty periods, weighted targets, dated assignments and authorization. The security advisor flags the intentionally authenticated definer RPC; its private scoped-facts function enforces tenant membership and assignment access. No anonymous grant or direct table access was introduced.
