# Completing missing economic-unit history

The unit editor can add a separate period before the first existing period. Operators select a subset of the first period's vehicle, project and employee references, a historical start date and a reason. Existing periods and their locks are retained.

The Hub requires a matching preview signature and current unit revision; it rejects overlapping active-unit references. The preview lists unassigned vehicle/project financial amounts from the active prepared generation. Employee-only effects can add further rows after preparation. Saving records extend_history with previous periods, selected references and reason, then queues the normal report rebuild.

Overview shows missing-unit revenue and cost for the exact active period, cost centre and filters. Matching shows missing-unit amounts for the whole chosen period and all cost centres, and separately shows invalid import rows excluded from reporting. These amounts are explanatory, not extra costs or revenue. Historical equipment combinations must be selected by the operator; no global backdating is performed.
